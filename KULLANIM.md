TÜRKÇE KLAVYE ANTRENÖRÜ
Hazırlayan: Aykut BOZALAN

TARAYICIDA DOĞRUDAN KULLANIM
https://aykido.github.io/KlavyeTrain/ adresini açın.
Kurulum gerekmez. Web sürümündeki kayıtlar bu web adresi ve tarayıcıya bağlıdır;
indirilen uygulamanın geçmişiyle birleştirilmez.

WINDOWS KURULUMU
1. GitHub deposunun Releases bölümünden KlavyeTrain-v…-Windows-Portable.zip indirin.
2. ZIP dosyasına sağ tıklayıp Tümünü Ayıkla seçeneğini kullanın.
3. Çıkardığınız klasörde Kur.cmd dosyasına çift tıklayın.
4. Masaüstündeki KlavyeTrain kısayolunu açın.

Program kullanıcı hesabınızın %LOCALAPPDATA%\KlavyeTrain klasörüne kurulur.
Yönetici yetkisi, Node.js, Python veya internet bağlantısı gerekmez.
Güncel Edge, Chrome veya Firefox tarayıcısı gerekir. Varsayılan tarayıcınız açılır.
Kurulum Windows PowerShell kullanır; kurum politikası betikleri engelliyorsa
taşınabilir kullanımı seçin veya kurumun bilişim sorumlusuyla görüşün.

KURMADAN KULLANIM / macOS / LINUX
ZIP içindeki index.html dosyasını bir web tarayıcısıyla açın.
Uygulama tek dosyadır; kelimeler, tasarım ve tüm kod içinde bulunur.
Dosyayı sabit bir klasörde tutun. Windows kurulum betikleri diğer sistemlerde
kullanılmaz. Kaynak kod ZIP'i yerine Releases içindeki hazır paketi indirin.

İLK ÇALIŞMA
Türkçe F veya Türkçe Q seçin. Bu seçim bilgisayarınızın klavye dilini değiştirmez;
işletim sistemindeki klavye düzeninizle aynı seçimi yapın.
Önce Klavyeyi tanı bölümünden başlayın. Kelime ve cümleleri Enter ile tamamlayın.
Backspace ile sondan düzeltin. Süre ilk girişte başlar.
Sekme değiştirildiğinde çalışma duraklar; Devam et düğmesiyle sürdürün.
Ders modunda süre, seviye ve hedefleri öğretmeninizin verdiği şekilde seçin.

YARDIM VE DİKTE
Ayarlar bölümünde dört yardım seviyesi, tema, büyük yazı ve yüksek kontrast var.
Sesli dikte için cihazda Türkçe konuşma sesi bulunmalıdır. Ses sağlayıcısına
bağlı olarak internet gerekebilir; diğer çalışmalar çevrimdışı kullanılabilir.

KAYITLAR VE GÜNCELLEME
Son 20 çalışma yalnızca kullandığınız tarayıcıda saklanır. Kişisel bilgi istenmez.
Dosyadan açılan uygulamalarda kayıt davranışı tarayıcıya bağlıdır. Dosyayı taşımak,
tarayıcı değiştirmek veya tarayıcı verilerini silmek geçmişi görünmez kılabilir.
Gelişimim bölümünden sonuçları JSON olarak dışa aktarabilirsiniz. Bu sürümde
JSON içe aktarımı yoktur; dışa aktarma arşivleme ve ileride analiz içindir.
Yeni sürümün ZIP'ini çıkarıp Kur.cmd dosyasını yeniden çalıştırın. Aynı kurulum
konumu korunur. Güncellemeden önce sonuçlarınızı dışa aktarmanız önerilir.
Güncellemeler otomatik indirilmez.

KALDIRMA
%LOCALAPPDATA%\KlavyeTrain klasöründeki Kaldir.cmd dosyasını çalıştırın.
Uygulama dosyaları ve kısayollar kaldırılır; tarayıcı kayıtları korunur.
Taşınabilir kullanımı kaldırmak için indirdiğiniz klasörü silebilirsiniz.
